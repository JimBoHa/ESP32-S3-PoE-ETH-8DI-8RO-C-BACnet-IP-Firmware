Preparing

Install firmware

INITIAL INSTALLATION / RECOVERY

Keep a recovery copy

Optional full backup of the firmware and settings currently on this controller. Allow several minutes.

Installation replaces the current firmware and erases saved settings, including the admin key. Disconnect controlled relay loads before installing.

Save your admin key

REQUIRED FOR MANAGEMENT

This private key lets you configure the device, control relays, and update firmware. Keep the downloaded file somewhere safe.

While the controller is running, hold BOOT for 3 seconds, then release it. Do not press RESET. This allows key download for 60 seconds.

The key stays on your computer. This installer does not upload it, add it to device links, or save it in browser storage.

Connect Ethernet

Connect Ethernet to a network with DHCP. Your device address will appear here.

Connection help

Device does not appear

Use a data-capable USB-C cable and another USB port. Close serial monitors or other tabs using this device. Select “USB JTAG/serial debug unit” when prompted.

Cannot enter flashing mode

Keep USB connected. Hold BOOT, tap RESET, then release BOOT. Try connecting again. If macOS shows an accessory prompt, allow the connection.

Firmware installed, setup interrupted

Reconnect here to continue setup. You do not need to erase the device again. If key download is locked, hold BOOT for 3 seconds while the firmware is running.

Future firmware updates

Open your device’s web interface and use its Firmware tab with the admin key. Ethernet updates preserve settings. Use USB installation for initial setup or intentional recovery.
