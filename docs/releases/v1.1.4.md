# BACnet IO 1.1.4 — generic publication defaults

This release packages the current firmware with generic network defaults.
DHCP remains enabled for a fresh controller. Static address placeholders and
reusable examples use RFC 5737 documentation networks; actual deployment
settings belong in private commissioning configuration. Stored controller
settings are not replaced by these publication defaults during Ethernet OTA.

The cumulative firmware changes are described in the
[1.1.4 development notes](v1.1.4-dev.md). Historical test results in those notes
belong to their recorded builds and do not establish hardware validation for
this release.

## Verification and limits

Release preparation uses the pinned ESP-IDF 5.5.4 toolchain and host tests.
No hardware deployment or validation is claimed for 1.1.4. A local build and
host tests do not establish physical relay behavior, supervisory command
restoration, or endurance. Installation and field acceptance remain separate
authorized activities.

## Packages

The matching release tag and embedded application version are `v1.1.4` and
`1.1.4`. The release archives are `bacnet-io-v1.1.4.zip` and
`bacnet-io-v1.1.4.tar.gz`; each includes `firmware-ota.bin`,
`initial-flash.bin`, `manifest.json`, `SHA256SUMS`, and dependency licenses.
Follow the [installation guide](../BROWSER_INSTALLER.md) when an installation
is authorized.
